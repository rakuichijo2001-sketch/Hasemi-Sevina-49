## Structural review checklist

- `tinyqv_registers` declares a rotating register array for RV32E registers
  `x1..x15`, with `x0`, `gp`, and `tp` handled separately. The RTL implies
  13 x 32 = 416 state bits before CPU control/bridge state; confirm their mapped
  FF count and any additional mux/rotation cost.
- TinyQV instruction fetch includes a four-entry 16-bit buffer
  (`instr_data[0:3]`, 64 bits). Confirm how the target synthesis maps it; it is
  a small core buffer, not program storage.
- The only external Flash/PSRAM arrays are in `test/sim_qspi.v`; that file is
  absent from the production `info.yaml` source list.
- TinyQV rotating register file maps to explicit sequential/combinational
  cells rather than an accidental bulk FF memory.
- No program ROM, data RAM, or testbench memory is inferred in silicon.
- CPU, MMIO and QSPI logic remain live and are not optimized away.
- Cell and mux growth is explained by the imported CPU/QSPI subsystem.
- Lint, latch, unmapped-instance and synthesis-check warnings are reported,
  not waived.
