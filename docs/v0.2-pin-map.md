# Hasemi-Sevina-49 v0.2 pin map

The v0.1 dedicated inputs and outputs are preserved. All bidirectional pins are
assigned to the shared external QSPI memory bus.

## Dedicated inputs

| Pin | Function | Notes |
|---|---|---|
| `ui_in[0]` | external SPI SCLK | Hasemi register access, Mode 0, <=2 MHz |
| `ui_in[1]` | external SPI MOSI | Hasemi register access |
| `ui_in[2]` | external SPI CS_N | inactive high; also arbitrates register bank |
| `ui_in[3]` | TICK_1HZ | asynchronous input synchronized by Hasemi |
| `ui_in[4]` | EXT_FAULT | asynchronous input synchronized by Hasemi |
| `ui_in[7:5]` | reserved | tied into unused reduction only |

## Dedicated outputs

| Pin | Function |
|---|---|
| `uo_out[0]` | external SPI MISO |
| `uo_out[1]` | ALERT |
| `uo_out[2]` | CRITICAL |
| `uo_out[3]` | SENSOR_FAULT |
| `uo_out[4]` | WATCH |
| `uo_out[5]` | WARNING |
| `uo_out[6]` | HEARTBEAT |
| `uo_out[7]` | IRQ |

## Bidirectional QSPI memory pins

This mapping is verified from TT06 `tt_um_MichaelBell_tinyQV` source rather
than copied from a diagram.

| Pin | Function | Direction during command/address/write | Direction during read data | Reset |
|---|---|---|---|---|
| `uio[0]` | Flash CS_N | output | output | input (`oe=0`), output value high |
| `uio[1]` | SD0 | output | input | input |
| `uio[2]` | SD1 | output | input | input |
| `uio[3]` | QSPI SCK | output | output | input (`oe=0`), output value low |
| `uio[4]` | SD2 | output | input | input |
| `uio[5]` | SD3 | output | input | input |
| `uio[6]` | PSRAM A CS_N | output | output | input (`oe=0`), output value high |
| `uio[7]` | PSRAM B CS_N / reserve | output | output | input (`oe=0`), output value high |

`uio_out` and `uio_oe` are always driven to known values. Only one chip select
may be active low. During QSPI read data all four SD output-enables are zero;
during command, address and PSRAM write phases all four are one. The external
memory devices must not drive SD lines outside their selected read phase.

## Boot/reset electrical contract

While reset is low, all `uio_oe` bits are zero. The external board may therefore
prepare flash continuous-read mode, PSRAM QPI mode and drive the upstream
latency code on SD2:SD0. Reset must remain asserted for clock edges so the
controller samples that code. After reset release, the controller owns chip
select and SCK pins and changes SD direction by QSPI phase.
